:::note[Scope]
Written for **builders**, insect classes first — 150&nbsp;g fairyweight through
3&nbsp;lb beetleweight. Numbers, materials, and examples target those classes.
Heavier classes share the principles; the magnitudes change. Rules content
tracks the **SPARC** ruleset (see [Rules &amp; Compliance](/rules/sparc-construction/)).
:::
